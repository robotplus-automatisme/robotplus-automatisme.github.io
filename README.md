# ROBOT+ — guaranteed-styled homepage

This version intentionally uses a self-contained `index.html`:
the CSS is embedded directly in the page, so the visual design does not
depend on a Jekyll layout being applied correctly.

## GitHub Pages

Upload the CONTENTS of this folder to the repository root.

The important files are:
- `index.html`
- `assets/images/...`
- `_config.yml`

Do not upload only `index.html`: the images are part of the design.
