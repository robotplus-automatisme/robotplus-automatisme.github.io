# ROBOT+ — homepage v4

This version uses the exact hero and building visuals visible in the approved
design rendering, the white-filled R/B/T logo, matching calendar/pin/phone/mail
icons, and a real OpenStreetMap map centered on Marnaz in the footer.

Upload the CONTENTS of this folder to the GitHub Pages repository root.

Required:
- index.html
- _config.yml
- assets/images/*

The footer map loads Leaflet/OpenStreetMap from the internet, so GitHub Pages
will display it when the site is online.
