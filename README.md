# ROBOT+ — exact homepage design

This version intentionally focuses on reproducing the supplied homepage mockup:
dark header, yellow/black ROBOT+ identity, large hero, angled capability band,
company block, 8 solution cards, project CTA and dark footer.

The page is implemented as Jekyll and is ready for GitHub Pages.

## Run

```bash
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000.

## Notes

The structure and styling are the priority in this version. Content from the supplied PDFs will be added after the homepage design is approved.
