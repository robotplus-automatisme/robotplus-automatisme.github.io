# ROBOTPLUS — Jekyll / GitHub Pages

Website starter for ROBOTPLUS, Marnaz (France).

## Run locally

Requirements: Ruby, Bundler and Jekyll.

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Publish on GitHub Pages

1. Create a GitHub repository, e.g. `robotplus-site`.
2. Copy the contents of this project into the repository.
3. In **Settings → Pages**, select **GitHub Actions** if using a custom workflow, or configure Pages to build from the repository branch when supported.
4. Update `_config.yml` with the final `url` and `baseurl` if needed.

## Content to replace

The current site intentionally contains a mix of public baseline information and clearly marked placeholders. Replace these with the company's approved material:

- logo / visual identity
- company history and team
- exact services and technologies
- photos and project references
- phone and email
- legal information
- customer references
- French / English translations
- cookie/privacy pages if required
