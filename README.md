# ROBOT+ — homepage

Self-contained GitHub Pages / Jekyll-compatible homepage for ROBOTPLUS, Marnaz.

## Included
- French, English, Italian, German and Spanish language switching from the top-right language control.
- Attached ROBOT+ logo supplied for this version.
- Hero copy translated in every language.
- Capability-strip icons extracted from the approved rendering so the yellow symbols match the rendering.
- Solution-card imagery cropped from the approved rendering for a direct visual match.
- Solution cards with bold white titles, smaller regular white descriptions, and yellow arrows only.
- Clickable phone number and email; address opens the exact Marnaz address in Google Maps.
- Smaller grey France silhouette with a yellow location pin.
- Legal company identifiers in the footer: SIREN, SIRET, VAT number, RCS and NAF.

## Main file
`index.html`

The page is intentionally self-contained (CSS and translations are embedded) so it renders reliably on GitHub Pages/Jekyll without depending on a theme layout.

- Language flags are stored as local SVG assets for consistent rendering across Firefox, Chrome, Edge, macOS and Windows.
